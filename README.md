# 工作台 Workstation

Python + PySide6 编写的 Windows 工具箱，参考 uTools 的统一入口模式。支持搜索、键盘启动、系统托盘、全局快捷键和自动发现工具模块。现有工具包括截图标注、倒计时、随手笔记。

## 启动

需要 Windows 10/11 和 64 位 Python 3.10 或更新版本。首次运行时，在仓库根目录创建虚拟环境并安装依赖：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

安装后也可双击 **run.bat** 启动。思刻编辑区使用 Qt WebEngine，由 `requirements.txt` 中的 PySide6 Addons 提供。

## 工具箱入口

- 启动后，工作台收在主屏幕右侧中部。把鼠标移到侧边的箭头按钮上，面板会沿右侧铺满屏幕可用高度并避开任务栏，移出面板后自动收起。
- 点击面板顶部的「固定」可保持展开，点击「取消固定」恢复自动收起。
- 左右拖动面板的左边线可调整宽度。工作台始终贴住屏幕右侧，重启后恢复上次宽度。
- 默认用 **Alt+Space** 呼出工具箱。首页显示可用工具，输入名称、关键词、拼音或缩写即可切换到搜索结果，如 `截图`、`jt`、`timer`、`djs`。
- 使用 ↑ ↓ 选择、Enter 打开，也可以点击工具卡片。
- 右键工具可收藏或取消收藏。收藏保存在本机，显示在首页顶部。
- Esc 或面板右上角的 × 可收起面板并取消固定，已开启的工具继续运行。
- 点击工作台右上角的「彻底退出」可结束后台运行并释放全局快捷键。系统托盘图标默认隐藏，可在「设置」中开启。开启后可以通过托盘菜单启动工具、重新注册快捷键或退出。
- 每个工具只创建一个实例，重复打开复用现有窗口和状态。
- 从面板齿轮、**Ctrl+,** 或托盘打开设置，可以修改呼出和截图的快捷键，保存后即时生效。发生冲突时会显示具体组合键，也可以继续从侧边或托盘打开工作台。

## 常用路径

- 从桌面或资源管理器拖入文件和文件夹。拖到分组标签上可直接加入该组，拖到列表或提示区域会加入当前分组。
- 默认有「分组1」和「分组2」，已有常用路径会放入「分组1」。可新增分组或重命名当前分组。
- 单击条目可以打开，右键可以复制路径或移除条目。点击「打开本组」可一次打开当前分组里的所有项目。
- 分组和路径保存在本机。添加或移除条目只修改工作台中的记录。

## 截图与标注

- 默认用 **Alt+A** 启动截图。鼠标悬停会标出窗口或对话框边界，单击选中，拖动可自由框选。选中后可在原地用工具条添加矩形、箭头、画笔或马赛克。点「完成」或按 **Enter / Ctrl+C** 保存 PNG、复制到剪贴板并加入队列。可在桌面或资源管理器文件夹的空白处用 **Ctrl+V** 粘贴为 PNG 文件，也可在支持图片粘贴的应用里直接粘贴图片。
- 使用默认截图快捷键时，**Ctrl+Alt+Z** 也可触发截图。若 Alt+A 被其他程序占用，可直接使用这个备用键。
- 截图时默认保留当前工作台。若希望从截图里排除工作台，可开启「截图与标注」卡片上的「截图时隐藏工作台」。点卡片或按截图快捷键均使用这个设置。
- 每按一次截图快捷键可截一张，按 Esc 或右键可取消当前框选。右侧截图队列将最新截图放在最左边，悬停高亮，移到队列边缘会横向滚动。单击重新复制，双击打开标注。截图文件保存在应用数据目录的 `captures` 文件夹。
- 点击截图队列标题旁的「打开文件夹」可进入截图保存目录，队列为空时也可使用。
- 从队列打开的截图可直接关闭。需要保留标注时，请先复制或保存。
- 从队列打开截图后，可点击「上一张」「下一张」或按 **← / →** 浏览同批截图，切回时可继续当前窗口里的标注。
- 支持矩形、圆形、箭头、画笔、文字、马赛克及颜色、粗细设置。
- **Ctrl+Z / Ctrl+Y** 撤销 / 重做；**Ctrl+C** 复制；**Ctrl+S** 保存 PNG；**Enter** 复制并关闭；**Delete** 撤销最近标注；**Esc** 关闭编辑窗口。
- 保留 `python screenshot.py` 独立截图入口，可从其托盘菜单标注最近的截图。建议与工具箱二选一运行，避免快捷键冲突。
- 在单个屏幕内框选时，PNG 保留屏幕原始像素。跨不同缩放比例的屏幕时，以框选范围内最高的缩放比例合成。当前不支持长截图及已有标注的移动修改。

## 倒计时

- 自定义时、分、秒，或选择 1 / 5 / 10 / 25 分钟预设。
- 支持开始、暂停、继续、重置、完成后再来一次，以及窗口置顶。
- 可调节窗口不透明度，也可切换到简约模式。
- **Enter** 执行开始、暂停、继续或再来一次，**Delete** 重置，**Esc** 收起窗口并继续后台计时。
- 使用单调时钟计算剩余时间，界面刷新延迟不会逐次累积误差。
- 关闭窗口仍在后台计时，到时响铃并显示倒计时窗口。开启工作台托盘图标后也会发送系统托盘通知，Windows 勿扰模式可能隐藏该通知。
- 记住上次设置的时长；退出程序不保留正在运行的倒计时。退出时如计时未结束会提示。
- 应用只在电脑运行时发出提醒，不会唤醒休眠电脑。

## 随记

- 在工作台搜索 `随记`、`思刻`、`笔记` 或 `notes`，也可从托盘菜单打开。
- 可新建多条笔记，左侧搜索标题和正文；未输入标题时显示“未命名笔记”。
- 若工作台旁有 `Scripta` 仓库，会自动加载其中的编辑器。也可点击「选择思刻目录」指定思刻桌面版目录、源码目录，或其中的 `app` / `web` 目录。
- 接入后，新笔记直接使用思刻的可视、段落和源码模式。已有富文本笔记可继续使用原编辑器，也可点击「创建思刻副本」生成 Markdown 笔记。文字颜色和下划线等格式可能在转换中丢失，原笔记仍可查看和编辑。
- 在列表中按 **Enter** 进入正文，按 **Delete** 可确认删除。思刻中的 **Esc** 由编辑器处理，关闭窗口时会保存。
- 停止输入约 0.6 秒后自动保存；Ctrl+S 手动保存。切换笔记、关闭窗口和退出工作台时也会保存。
- 保存失败会保留当前编辑内容并提示；未成功保存时会阻止切换和正常退出。
- 可将当前正文导出为 HTML。思刻编辑区用于编辑本地 Markdown 正文，笔记列表和保存由随记负责。
- 笔记存储在本地 `notes.sqlite3`，与日志处于同一应用数据目录（通常为 `%LOCALAPPDATA%\TinyTools\TinyTools`）。退出工作台后复制该文件即可备份。
- 删除笔记需要确认，删除后不可撤销；删除最后一条后会创建空白笔记。

## 扩展一个新工具

将 [examples/hello_tool.py](examples/hello_tool.py) 复制到 `tinytools/plugins/hello.py`，修改名称与实现，再重启工具箱即可。无需修改主窗口、托盘菜单或注册表代码。

模块必须提供：

```python
from tinytools.core import ToolSpec

SPEC = ToolSpec(
    id='unique-tool-id',
    name='工具名称',
    description='一句话说明用途',
    keywords=('关键词', 'english', 'pinyin'),
    symbol='◇',
)

def create_tool(context):
    return YourTool(context)
```

返回的工具实例实现三个方法：

| 方法 | 作用 |
| --- | --- |
| `activate()` | 打开或激活工具；窗口型、一次性动作均可 |
| `can_exit()` | 返回是否允许退出，处理未保存内容等情况 |
| `shutdown()` | 退出时停止计时器、线程等资源 |

`context` 提供 `app`、`settings`（QSettings）、`notify(title, message)`、`hide_launcher()`。设置键使用自己的工具 ID 前缀，避免冲突。

可选全局快捷键：在 `ToolSpec` 指定 `shortcut='Ctrl+Alt+H'`、`hotkey_key=ord('H')`、`hotkey_modifiers=0x0003`。修饰键位为 Alt=1、Ctrl=2、Shift=4、Win=8；组合使用按位或。`shortcut` 是显示文字，实际注册由两个数字字段决定。不要与 Alt+Space 或其他工具的快捷键重复。

自动发现会导入 `tinytools/plugins/` 下的模块和包；窗口应放在 `create_tool()` 中创建，耗时工作不要阻塞 UI 线程。模块加载或打开失败会记录日志，并保留其他工具入口。这里是本地可信 Python 插件机制，没有沙箱，请只加入自己信任的代码；它不兼容 uTools 的 JS 插件格式。

## 目录

```text
main.py                    工具箱启动入口
screenshot.py              截图与编辑实现，兼容独立启动
tinytools/app.py            搜索面板、托盘、快捷键、应用生命周期
tinytools/capture_queue.py  截图缩略图队列和保存目录入口
tinytools/common_paths.py   常用路径、拖放和分组
tinytools/core.py           工具协议、注册和自动发现
tinytools/timer.py          可独立测试的倒计时逻辑
tinytools/plugins/          工具模块
examples/hello_tool.py      可直接复制的扩展模板
tests/                     截图、工作台、倒计时和随记测试
```

设置通过 Qt QSettings 存储在当前用户下；日志位于 Qt AppLocalDataLocation 对应目录中的 `tinytools.log`（通常在 `%LOCALAPPDATA%\TinyTools\TinyTools`）。截图及编辑均在本地完成。
